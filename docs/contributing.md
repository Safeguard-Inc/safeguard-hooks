# Contributing

See the repository's `CONTRIBUTING.md` for the contribution guide: branch
and commit conventions, the one-improvement-per-commit rule, and the
definition of done (fmt, clippy `-D warnings`, the full test suite, and the
schema checker). The `docs/testing.md` matrix explains what each suite
protects, and `docs/architecture.md` maps where new code belongs — keeping
policy rules out of the enforcement layer and evidence out of the engine.
